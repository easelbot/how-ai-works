# How AI Works: code from the Easelbot series

Runnable code from **How AI Works**, the series on the [Easelbot YouTube channel](https://www.youtube.com/@Easelbot):
AI & tech, drawn easy. Each episode gets its own folder: small, readable, and you can run it on your laptop.

| Episode | Topic | Code |
|---|---|---|
| Ep 1 | Everyone Says AI Agents Will Replace Jobs. Nobody Tells You Why. | [`ep01-ai-agents/`](ep01-ai-agents/): a tiny agent with all 5 pillars (brain, hands, memory, loop, guardrails) |

## Quick start
```
git clone https://github.com/easelbot/how-ai-works
cd how-ai-works/ep01-ai-agents
python agent.py --offline        # no API key needed
```
Every folder has its own README with what it shows and how to run it.

All example data (shops, orders, customers) is made up. Code is MIT licensed: copy it, change it, learn from it.
